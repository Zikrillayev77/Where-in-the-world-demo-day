<p align="center">Dunyo davlatlari haqida ma'lumot beruvchi ilova va bayroqlar bo'yicha viktorina — Demo Day loyihasi.</p>

## ✨ Imkoniyatlar

- 🗺️ Barcha davlatlar bayroqlari bilan
- 🔎 Davlatni nomi bo'yicha qidirish
- 🧭 Mintaqa (region) bo'yicha filtr
- 🪟 Davlat haqida batafsil ma'lumot oynasi
- 🌙 Qorong'i rejim (tanlov `localStorage` da eslab qolinadi)
- 🏁 **Viktorina** (`quiz.html`) — bayroqqa qarab davlatni toping va ball yig'ing

## 🔌 Ishlatilgan manbalar

- [ISO-3166 davlatlar ro'yxati](https://github.com/lukes/ISO-3166-Countries-with-Regional-Codes)
- [CountriesNow API](https://countriesnow.space/) — poytaxtlar
- [FlagCDN](https://flagcdn.com/) — bayroq rasmlari

## 🚀 Ishga tushirish

Hech qanday o'rnatish kerak emas:

```bash
git clone https://github.com/Zikrillayev77/Where-in-the-world-demo-day.git
cd Where-in-the-world-demo-day
```

So'ng `index.html` faylini brauzerda oching (yoki VS Code'dagi **Live Server** kengaytmasi orqali).
